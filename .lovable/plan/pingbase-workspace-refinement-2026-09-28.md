# Pingbase workspace refinement

## Outcome
Update the authenticated Pingbase workspace to the selected clean operational direction while preserving every existing workflow and the Veya design system.

## Changes
- Remove the global 0.9 scale transform so the interface renders at true 1×.
- Refine the shared navigation into a clearer light workspace shell with stronger grouping, calmer selected states, and compact icon-led rows.
- Update shared page framing, headers, secondary navigation, controls, and content surfaces to match the selected reference density and hierarchy.
- Polish the inbox’s conversation list, message area, customer panel, handover notice, and AI/human controls without changing behavior.
- Polish the contacts page search, toolbar, table, and contact drawer using the same shared visual language.
- Keep all colors, spacing, radii, shadows, and typography sourced from Veya tokens and components.

## Validation
- Check the relevant pages at desktop width for overflow, clipping, and readable density.
- Confirm the app builds successfully and existing inbox actions remain available.
